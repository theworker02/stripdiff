# stripdiff

Strip filesystem diff paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/stripdiff/

## Install / run

```bash
git clone https://github.com/theworker02/stripdiff.git
cd stripdiff
node src/cli.js
node --test
```
